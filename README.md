> [!WARNING]
> The script is written for Arch Linux only!

## Usage
1. Clone the repo
```
git clone https://github.com/owlsly94/hyprland.git
cd hyprland
```
2. Make sure the `install.sh` script is executable and execut it
```
chmod +x install.sh
sh install.sh
```
3. Make sure that gamemode deamon is running:
```
gamemoded -t
```
4. To set a wallpaper, either use:
for random wallpaper `WINDOWS KEY + W` <br>
or if you wanna choose your wallpaper `WINDOWS KEY + SHIFT KEY + W`
